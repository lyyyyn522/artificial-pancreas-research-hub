# 论文写作与呈现

本目录用于整理人工胰腺、血糖预测及相关 AI 研究的论文写作流程、图表规范和排版资源。

## 计划内容

- `outlines/`：论文结构与章节提纲
- `writing-guides/`：摘要、引言、方法、结果和讨论的写作检查表
- `figure-guidelines/`：科研图表设计与导出规范
- `templates/`：期刊或会议模板及其来源说明
- `checklists/`：投稿前核对清单

## 写作流程

1. 明确研究问题、贡献和适用范围。
2. 根据实验记录撰写方法与结果，确保数值和代码一致。
3. 用文献支持背景与讨论中的事实性陈述。
4. 检查图表、单位、缩写、引用和局限性。
5. 根据目标期刊或会议的官方要求调整格式。

## 规范

- 不编造数据、结果、引用或研究贡献。
- 区分本研究结果、既有文献结论和作者解释。
- 记录模板及格式要求的官方来源和核对日期。
- 图表应清晰呈现数据，不通过视觉设计夸大效果。
