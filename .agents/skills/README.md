# 研究工作流 Skills

本目录用于整理可复用的 AI 工作流说明，辅助完成文献整理、实验记录和论文准备。

## 计划建设的 Skills

- `literature-audit/`：检查文献条目与关键结论是否有来源支持
- `experiment-to-paper/`：根据实验记录整理方法和结果初稿
- `figure-review/`：检查科研图表的标签、单位、图例和可读性
- `manuscript-check/`：检查论文结构、引用、数值一致性和占位内容

## Skill 编写规范

每个 skill 单独放在一个目录中，并包含 `SKILL.md`，说明：

- 适用场景与不适用场景
- 所需输入及其格式
- 执行步骤
- 输出格式
- 事实核对与质量检查要求
- 医学、安全、数据隐私或版权边界

## 使用边界

Skills 是研究辅助工作流，不替代研究者对文献、数据、实验结果和论文内容的核验，也不用于临床决策或自动给药。
