# LLM 与人工胰腺研究

本目录用于整理大语言模型（LLM）与血糖预测、人工胰腺研究结合的文献、方法和实验设想。

## 研究方向

- **文献辅助**：检索、归纳和核对研究资料，并保留来源。
- **血糖时间序列预测**：评估 LLM 或时序基础模型在血糖预测任务中的表现。
- **多模态与上下文信息**：研究如何结合 CGM、饮食、运动等信息；记录数据来源与隐私条件。
- **研究工作流**：探索 LLM 辅助代码、实验记录和论文写作的方法。

## 计划内容

- `literature-notes/`：LLM 与血糖预测相关论文阅读卡
- `ideas/`：待验证的研究问题与假设
- `experiments/`：实验设计、对比基线与结果
- `risks-and-evaluation.md`：风险、评估要求与失败案例

## 评估与记录原则

- 将研究设想与经过实验验证的结果明确区分。
- 与简单、强基线在相同数据划分和预测时距下比较。
- 记录数据泄漏、个体间泛化、错误输出和不确定性等问题。
- 对 LLM 生成的文献摘要和研究结论回查原始来源。

## 安全边界

LLM 输出仅供科研与教学使用，不用于个人医疗建议、临床决策或真实设备的自动给药。
