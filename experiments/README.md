# 实验记录

本目录用于记录血糖预测与人工胰腺相关研究的实验方案、配置、结果和复现步骤。

## 计划内容

- `protocols/`：实验方案与评估流程
- `configs/`：模型和训练配置
- `results/`：实验结果摘要与图表索引
- `reproduction/`：复现实验的步骤与环境说明

## 每项实验应记录

- 实验目的与研究问题
- 数据集及其版本、获取方式
- 纳入和排除规则
- 训练集、验证集与测试集的划分方法
- 预处理步骤及随机种子
- 模型、超参数和软件环境
- 评价指标与预测时距
- 结果、失败尝试和局限性
- 代码版本或对应的 Git commit

## 实验规范

- 先确定测试集划分，再进行模型开发和调参，避免数据泄漏。
- 不只报告表现最好的结果；说明比较对象和实验条件。
- 将已复现结果、文献报告结果和待验证设想明确区分。
