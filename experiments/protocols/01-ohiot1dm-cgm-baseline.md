# OhioT1DM 2018 CGM 个体化血糖预测基线实验

- 实验编号：EXP-001
- 数据集：OhioT1DM 2018
- 受试者：559、563、570、575、588、591
- 实验类型：离线、个体内血糖预测
- 当前状态：实验协议
- 原始数据：仅保存在本地，不上传 GitHub

## 1. 研究问题

对于 OhioT1DM 2018 数据中的每位受试者，使用其历史 CGM 血糖值训练个体化模型，能否在 30 分钟和 60 分钟预测时距上优于持续值预测基线？

本实验只研究离线血糖预测，不研究真实设备控制、胰岛素自动给药或临床治疗效果。

## 2. 研究假设

主要假设：

> 对每位受试者单独训练的 Ridge 回归模型，在相同测试目标和相同有效样本集合上，能够降低 RMSE 和 MAE。

比较模型：

1. Persistence baseline：未来血糖等于当前血糖。
2. Individual Ridge：每位受试者单独训练一个 Ridge 回归模型。

## 4. 预测任务

分别进行两个单点预测任务。

### 4.1 30 分钟预测

给定时刻 `t` 及之前可获得的 CGM 历史，预测：

```text
y(t + 30 minutes)
```

### 4.2 60 分钟预测

给定时刻 `t` 及之前可获得的 CGM 历史，预测：

```text
y(t + 60 minutes)
```

两个预测时距分别训练、分别评价，不合并为一个指标。

## 5. 输入窗口

第一阶段使用最近 12 个 CGM 点作为输入：

```text
[t-55, t-50, t-45, ..., t-5, t]
```

由于 CGM 的目标采样间隔为 5 分钟，12 个点的首末时间跨度为 55 分钟。

注意：

- 12 个点不等于严格覆盖 60 分钟。
- 必须按照真实时间戳构造窗口。
- 不允许仅按照 XML 中的行号直接取第 6 行或第 12 行作为预测目标。
- 只有当所有历史时间点都存在时，才构造严格有效样本。
- 第一阶段不跨缺测区间插值。
- 第一阶段不使用未来信息填补历史缺失值。

## 6. 有效样本定义

对于预测时刻 `t` 和预测时距 `h`，样本必须同时满足：

1. 输入时间点 `t-55, t-50, ..., t` 均存在；
2. 目标时间点 `t+h` 精确存在；
3. 所有时间戳均能解析；
4. 输入和目标血糖值均为有效有限数值；
5. 输入窗口不跨越大于 5 分钟的缺测间隔；
6. 目标值来自官方测试文件；
7. 预测时刻之前不存在目标时刻之后的信息。

其中：

```text
h = 30 minutes 或 60 minutes
```

相邻 CGM 记录间隔大于 5 分钟时，不自动认为中间值可以被补齐。

## 7. 数据划分

### 7.1 官方训练／测试划分

保留 OhioT1DM 官方训练／测试文件，不重新随机划分官方测试集。

- 官方 training XML：用于模型开发
- 官方 testing XML：只用于最终测试评价

官方测试集不得用于：

- 选择模型
- 选择超参数
- 选择输入窗口
- 决定缺失值处理方法
- 选择性删除表现较差的样本

### 7.2 训练集内部划分

在每位受试者的官方 training XML 内，按时间顺序划分：

- 前 80%：模型拟合
- 后 20%：验证和 Ridge 超参数选择

不使用随机划分。

为降低时间窗口之间的边界重叠，训练和验证样本之间预留至少 60 分钟的时间间隔。

确定 Ridge 超参数后：

1. 使用完整官方 training XML 重新训练；
2. 使用固定模型在官方 testing XML 上评估；
3. 不根据测试结果重新修改超参数。

## 8. 模型定义

### 8.1 Persistence baseline

对于预测时刻 `t`：

```text
prediction(t+h) = glucose(t)
```

其中 `h` 分别为 30 分钟和 60 分钟。

Persistence 和 Ridge 必须使用完全相同的有效目标时间戳集合进行比较。

### 8.2 Individual Ridge

每位受试者单独训练一个 Ridge 回归模型。

输入：

```text
x(t) = [
    glucose(t-55),
    glucose(t-50),
    ...,
    glucose(t-5),
    glucose(t)
]
```

输出：

```text
y(t+h)
```

其中 `h` 为 30 分钟或 60 分钟。

模型设置：

- 每位受试者单独训练；
- 30 分钟和 60 分钟分别训练；
- 使用训练数据估计输入标准化参数；
- 不使用测试数据估计均值、标准差或其他预处理参数；
- Ridge 正则化参数只在训练集内部验证集上选择。

第一轮候选正则化参数：

```text
alpha ∈ {0.01, 0.1, 1, 10, 100}
```

如果实际实现使用了不同候选值，必须在实验结果中记录。

## 9. 评价指标

对 30 分钟和 60 分钟分别计算。

### 9.1 MAE

```text
MAE = mean(|prediction - actual|)
```

单位：

```text
mg/dL
```

### 9.2 RMSE

```text
RMSE = sqrt(mean((prediction - actual)^2))
```

单位：

```text
mg/dL
```

### 9.3 覆盖率

```text
Coverage = 有效评分目标数 / 测试文件目标总数
```

必须同时报告：

- 每位受试者的有效样本数；
- 每位受试者的测试目标总数；
- 每位受试者的覆盖率；
- 六位受试者的等权平均指标。

不能只报告合并所有受试者后的一个总体指标。

## 10. 结果比较规则

Persistence 和 Ridge 必须满足以下条件后才可以直接比较：

- 相同受试者；
- 相同预测时距；
- 相同目标时间戳；
- 相同缺测处理规则；
- 相同评价指标。

主要比较方式：

```text
Ridge RMSE 是否低于 Persistence RMSE
Ridge MAE 是否低于 Persistence MAE
```

相对改善率定义为：

```text
Improvement (%) =
(Persistence RMSE - Ridge RMSE)
 / Persistence RMSE × 100%
```

改善率只作为模型比较指标，不代表临床获益。

## 11. 预先设定的成功判据

本实验将以下条件作为继续开展模型研究的内部标准：

1. 30 分钟预测中，六位受试者等权平均 RMSE 相比 Persistence 至少下降 5%；
2. 至少 4/6 位受试者的 RMSE 得到改善；
3. Ridge 和 Persistence 使用相同有效测试目标；
4. 所有受试者的测试覆盖率均被明确报告；
5. 没有使用测试集调参或选择性删除测试样本。

满足以上条件，记为：

```text
支持继续研究 Ridge 及更复杂模型
```

未满足以上任一主要条件，记为：

```text
当前假设未得到支持
```

未满足成功判据不等于实验失败。负面结果也必须保留并记录。

上述 5% 和 4/6 仅用于研究推进决策，不是临床阈值，也不能证明模型安全有效。

## 12. 失败判据与停止条件

出现以下情况时，停止当前实验并先修正数据或协议：

- 发现训练集和测试集时间戳重叠；
- 发现模型使用了目标时刻之后的数据；
- 发现预处理参数使用了测试集；
- Persistence 和 Ridge 使用了不同的测试目标；
- 无法解释有效样本数量的变化；
- 训练或测试 XML 无法稳定解析；
- 结果依赖未经记录的手动删样本；
- 预测时距与实际时间戳不一致；
- 跨缺测区间构造了连续历史窗口；
- 未记录模型配置、代码版本或随机种子。

## 14. 实验边界

本实验属于小样本、离线、个体内预测实验。

本实验不能证明：

- 模型适用于其他糖尿病患者；
- 模型可以用于临床诊断；
- 模型可以用于胰岛素输注决策；
- 模型可以用于真实人工胰腺控制；
- 预测性能改善必然带来临床获益；
- 结果具有真实设备安全性。

所有模型和结果仅用于科研与教学。
