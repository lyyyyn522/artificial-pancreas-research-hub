# 人工胰腺闭环控制如何评价？

> **笔记性质：** 人工胰腺控制研究的评价框架  
> **适用范围：** 科研与学习  
> **重要边界：** 本文不提供胰岛素输注方案，不指导真实设备的控制或调参。

## 1. 预测评价与控制评价有什么不同？

血糖预测模型回答：

> “在时刻 `t`，模型对未来血糖的估计有多准确？”

闭环控制研究回答：

> “系统根据当前信息采取行动后，后续血糖状态、设备运行和风险表现如何？”

控制算法的行动可能改变后续血糖轨迹。因此，不能只拿一段固定的历史数据做离线预测，就推断接入控制后的效果。

| 评价对象 | 典型输入 | 典型结果 |
| --- | --- | --- |
| 离线预测模型 | 已记录的 CGM 等历史数据 | 预测误差、事件识别表现 |
| 闭环仿真系统 | 模拟人体、传感器、控制器和输注设备 | 模拟血糖轨迹、控制动作与系统异常 |
| 真实场景中的设备系统 | 按研究方案使用的实际设备 | 研究预先规定的效果、安全及可用性结果 |

这些层次各有用途，但证据不能互相替代。FDA 指出，计算机模型和实验室研究能帮助了解设备表现；要判断设备在真实场景中是否按预期工作及识别安全问题，仍需要临床研究。[1]

## 2. 先明确“控制了什么”

比较两种方法前，应写清楚：

- 系统是暂停输注、调整胰岛素输注，还是研究其他控制目标？
- 传感器、泵、通信和控制算法分别如何表示？
- 控制器每次获得哪些输入？多久更新一次？
- 是否需要用户输入进餐等信息？
- 是否存在预先定义的设备限制或异常处理机制？
- 对照方法是什么？除被比较的方法外，其他条件是否一致？

**不要仅凭“TIR 更高”就宣布某个控制算法整体更好。** 还要看低值区间、数据质量、异常场景和研究设计。

## 3. CGM 轨迹的常见结果指标

国际 CGM 共识使用以下指标描述一段时间内的血糖状态。[2]

| 指标 | 含义 | 报告时必须说明 |
| --- | --- | --- |
| TIR（time in range） | 在指定目标范围内的时间比例 | 范围上下限、计算时段和有效数据覆盖 |
| TBR（time below range） | 低于指定范围的时间比例 | 使用了哪个低值阈值或分层 |
| TAR（time above range） | 高于指定范围的时间比例 | 使用了哪个高值阈值或分层 |
| 平均葡萄糖值 | 观察期内的平均 CGM 值 | 单位、有效样本和计算方式 |
| 葡萄糖变异程度 | CGM 值的波动情况 | 所用统计量及其计算方式 |

例如，2019 年国际共识在**部分非妊娠成人**的 CGM 解读中使用 `70–180 mg/dL`（`3.9–10.0 mmol/L`）作为 TIR 范围，并区分更低和更高的区间。**不同人群和研究方案可能需要不同定义**；引用具体阈值时应同时说明来源、适用人群及研究目的。[2]

这些是研究中用于描述血糖状态的区间，**不是本仓库提供的个人治疗目标**。

### 数据覆盖情况同样重要

报告 TIR、TBR、TAR 时，还应报告：

- 观察了多少天或多少小时；
- 有效 CGM 数据覆盖了多少时间；
- 缺失时段如何处理；
- 结果是按受试者先计算后汇总，还是把所有读数合并计算。

如果传感器长时间没有读数，仅报告“有数据时的 TIR”，可能无法充分描述整个观察期。国际共识也强调数据充足程度对 CGM 解读的重要性。[2]

## 4. 不只看区间比例，还要看过程

完整的闭环评价应考虑：

1. **进餐时段：** 是否有进餐信息？餐后轨迹如何？
2. **夜间：** 与白天分开观察是否有不同表现？
3. **身体活动及其后续：** 数据或仿真是否包含相关场景？
4. **低值事件：** 事件定义、次数、持续时间与处理方式是什么？
5. **设备运行：** CGM、泵和控制器有多少时间能够按预期工作？
6. **用户参与：** 需要人工输入、确认或接管多少次？

如果研究没有覆盖某种场景，就应写“未测试”，而不是推断该场景安全。

## 5. 仿真评价应该怎样设计？

仿真（in silico）可以在受控环境中测试控制算法。设计时应说明：

- 模拟器名称和版本；
- 虚拟受试者及其差异；
- 进餐、活动和其他外部事件如何生成；
- 传感器误差、数据缺失及通信异常如何模拟；
- 胰岛素作用和设备行为如何表示；
- 对照控制方法与随机种子；
- 测试场景是否在开发前确定；
- 是否使用独立于调参场景的最终测试场景。

在仿真中可以研究异常输入或组件失效，但**这仍只是针对所用模型和场景的测试**。FDA 关于人工胰腺设备的资料指出，仿真模型应考虑人体代谢差异、CGM 与泵性能、胰岛素药代过程及血液与组织间液之间的差异。[3]

### 仿真报告必须标记的边界

- `模拟血糖` 不等于真实患者的临床结局；
- `模拟低值事件` 不等于真实临床严重低血糖事件；
- 在一个模拟器上表现较好，不代表在所有设备、人群或日常环境中表现较好。

## 6. 真实场景研究还需关注什么？

真实人体研究应遵循经批准的研究方案，由合格的研究与医疗团队实施。本仓库只整理研究方法，不提供开展人体试验或部署设备的操作指令。

阅读临床研究时，应检查：

- 纳入人群与排除条件；
- 对照组或对照阶段；
- 主要和次要结局是否预先确定；
- 观察时间及 CGM 数据覆盖；
- 不良事件与退出研究情况；
- 研究地点是受监测环境还是门诊、居家环境；
- 人工参与、训练及设备使用条件；
- 统计分析是否与研究设计匹配。

例如，一项为期六个月的随机多中心研究比较了闭环系统与传感器辅助泵治疗，并预先规定了 CGM 目标范围内时间等结局。引用此类结果时，应保留其人群、设备、对照和研究时长，不能把结果推广到所有系统。[4]

## 7. 比较两种控制方法的公平性

在**相同仿真研究**中比较控制器时，尽量保持：

- 相同虚拟受试者和测试场景；
- 相同传感器、泵及通信模型；
- 相同进餐、活动等外部条件；
- 相同观察时长；
- 相同的指标定义和缺失处理；
- 相同的运行限制与异常规则。

如果一个方法使用进餐预告，而另一个方法不能使用，比较结果应明确标注**输入信息不同**，不能只解释为“算法本身更优”。

## 9. 常见的过度解读

- **“预测 RMSE 较低，所以闭环控制更安全。”**  
  预测误差与控制后果是不同问题，需要分别验证。

- **“TIR 增加，所以系统没有低血糖风险。”**  
  应同时查看 TBR、事件、数据覆盖和其他预先规定的安全结果。

- **“仿真没有出现问题，所以真实患者使用也安全。”**  
  仿真只能说明特定模型及测试场景下的结果。

- **“两篇论文都报告 TIR，可以直接比较百分比。”**  
  人群、设备、研究时间、缺失处理、对照条件和区间定义可能不同。
