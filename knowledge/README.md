# 知识点

本目录整理人工胰腺、连续血糖监测（CGM）、血糖预测与闭环控制评价的基础知识。建议按以下顺序阅读；每篇笔记中的参考资料和待核实问题可用于继续深入学习。

> **使用边界：** 内容仅供科研与学习，不构成个人医疗建议，也不用于真实设备的自动给药决策。

## 如何使用本目录

- **初次阅读：** 从 `01` 读到 `10`；可先阅读[血糖预测研究概览](glucose-prediction-overview.md)，了解本仓库关注的问题。
- **设计预测实验：** 重点阅读 `04`、`05`、`06`、`07` 和 `09`。
- **阅读人工胰腺控制论文：** 重点阅读 `01`、`03`、`08` 和 `10`。
- **查找具体论文：** 前往仓库的 `literature/`；本目录侧重解释概念，不替代单篇论文阅读卡。
- **查找实现与结果：** 模型代码放在 `models/`，实验配置与结果放在 `experiments/`，数据集来源及许可记录放在 `datasets/`。

## 笔记维护规范

1. 尽量注明概念定义、适用范围、关键注意事项、参考资料和待核实问题。
2. 区分**原始研究结论**、**本仓库的解释**与**尚未验证的设想**。
3. 关键事实链接到可核对的原文、DOI 或官方资料；不要仅依据 AI 生成的摘要引用论文。
4. 涉及实验表现时，写明数据、人群、预测时距、评价方法以及研究属于离线、仿真还是真实场景。
5. 新增笔记后，更新本页链接，并在 GitHub 的 Preview 中检查导航是否正常。
