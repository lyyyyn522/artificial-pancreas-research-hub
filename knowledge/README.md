# 知识点

本目录系统整理人工胰腺、连续血糖监测（CGM）、血糖预测和相关评估方法的基础知识。

## 知识地图

### 1. 系统与生理基础
- 人工胰腺系统概览
- 血糖、胰岛素与葡萄糖调节基础
- CGM 的测量与数据特点

### 2. 血糖预测
- 血糖预测任务的定义
- 预测时距与预测目标
- 输入变量与预测窗口
- 基线模型与常见模型类别

### 3. 数据与评估
- 数据预处理与缺失值
- 训练集、验证集和测试集划分
- 数据泄漏及其防范
- 预测误差与低血糖风险评估

### 4. 人工胰腺控制
- 人工胰腺系统组成与信息流
- 血糖预测与控制决策的区别
- 仿真评估、风险与安全边界

## 笔记规范

每篇笔记尽量包含：

1. **定义**：概念是什么。
2. **研究意义**：它解决什么问题。
3. **系统中的作用**：它与 CGM、预测或控制有什么关系。
4. **关键注意事项**：常见误解、局限或风险。
5. **参考文献**：原始论文、权威指南或官方资料链接。
6. **待核实问题**：尚未确认的内容。

重要事实应能追溯到来源；文献结论、自己的解释和待验证设想要明确区分。本目录用于科研与学习，不用于个人医疗建议或自动给药决策。
