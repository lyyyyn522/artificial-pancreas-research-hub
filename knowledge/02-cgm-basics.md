# 连续血糖监测（CGM）基础

> **笔记性质：** 科研与学习用基础笔记  
> **适用范围：** 了解 CGM 数据及其在血糖预测研究中的作用  
> **重要边界：** 本文不构成医疗建议，不提供个人治疗方案或设备使用指导。

## 1. 什么是 CGM？

连续血糖监测（continuous glucose monitoring, CGM）是一种在一段时间内连续或频繁估计葡萄糖水平的监测方式。与传统指尖血糖测量提供单个时间点的读数不同，CGM 可形成随时间变化的数据序列，并可能提供趋势图、变化方向提示或警报功能。

CGM 数据既可以用于观察血糖变化，也可以作为血糖预测模型的输入。但 CGM 读数不应未经说明就被视为实验室血糖或指尖血糖的完全等价替代。

## 2. CGM 系统通常包含什么？

CGM 系统的具体设计因设备而异，通常包括：

| 部件 | 作用 |
| --- | --- |
| 传感器 | 采集与葡萄糖相关的传感信号 |
| 发射与通信部件 | 将传感器信息传送至接收设备或应用程序 |
| 接收设备或应用程序 | 显示估计读数、历史曲线、趋势信息或提醒 |
| 软件与算法 | 对传感器信号进行处理并生成设备显示的信息 |

多数皮下 CGM 传感器测量的是皮下组织间液中的葡萄糖相关信号，设备再通过算法生成并显示葡萄糖估计值。不同设备的传感器、信号处理方式、数据接收方式和标定要求可能不同。

## 3. CGM 与指尖血糖测量的区别

| 对比项 | CGM | 指尖血糖测量 |
| --- | --- | --- |
| 数据形式 | 连续或频繁的时间序列 | 单个时间点的测量值 |
| 测量部位 | 通常基于皮下组织间液信号 | 指尖毛细血管血液 |
| 可观察内容 | 读数、历史曲线和趋势 | 测量当时的数值 |
| 常见研究用途 | 变化趋势、预测、时间序列分析 | 参考测量或特定场景下的血糖测量 |

两种测量来自不同的生理部位和测量流程，因此在血糖快速变化时，读数可能不完全一致。研究中应记录 CGM 数据与参考测量的来源、时间对应关系和比较方法。

## 4. CGM 数据的常见特点

### 4.1 时间序列结构

CGM 数据通常由带时间戳的连续读数组成。具体记录间隔由设备和数据导出方式决定，不能假定所有设备都使用完全相同的采样间隔。

### 4.2 趋势信息

CGM 数据不仅包含单点数值，还可以展示一段时间内的变化轨迹。对于预测研究，模型可能使用近期读数序列来估计未来某个时间范围内的血糖。

### 4.3 估计值与误差

显示值是设备根据传感信号处理得到的估计值。误差可能来自传感器、信号处理、数据传输、时间对齐或参考测量等多个环节。比较设备或模型时，应说明使用了什么参考值和评估方法。

### 4.4 生理与处理延迟

组织间液中的葡萄糖变化与血液中的葡萄糖变化之间可能存在时间差；设备的滤波与信号处理也可能影响显示时间序列。延迟大小可能受设备、数据处理方式和血糖变化条件影响，不应把某个固定分钟数当成所有 CGM 的通用常数。

因此，进行预测或与其他测量对齐时，应明确时间戳含义、采样间隔和对齐方法。

## 5. 研究中常见的数据质量问题

- **缺失值：** 传感器暂时没有读数、通信中断或数据导出不完整。
- **不规则采样：** 实际数据时间间隔可能并非完全一致。
- **异常值：** 可能来自传感器误差、数据处理或记录问题，不能只凭数值极端就自动删除。
- **时间戳问题：** 时区、夏令时、重复时间或日期格式可能造成错位。
- **单位不一致：** 常见血糖单位包括 mg/dL 和 mmol/L；分析前要核对并统一。
- **设备差异：** 不同设备可能具有不同采样频率、传感器特性和信号处理流程。
- **受试者差异：** 不同个体的数据长度、缺失模式和血糖变化特点可能不同。

处理规则应在分析前写清楚，并保留原始数据来源和预处理记录。

## 6. CGM 在血糖预测中的作用

在血糖预测研究中，CGM 序列常用于构造模型输入。例如，研究者可能使用一段历史 CGM 数据预测未来某一时刻或一段时间内的血糖。

阅读或设计预测研究时，应明确以下信息：

1. **预测目标：** 预测单个未来读数、多个未来读数，还是风险类别？
2. **历史窗口：** 模型使用预测时点之前多长时间的数据？
3. **预测时距：** 预测未来多久？
4. **数据来源：** 输入与目标是否来自同一设备或同一测量方式？
5. **时间对齐：** 输入窗口和预测目标的时间戳如何对应？
6. **缺失处理：** 缺失值如何处理，是否会使用未来信息？
7. **评估对象：** 评估的是总体平均表现、每位受试者表现，还是跨受试者泛化？

### 示例：预测窗口

如果目标是在时间点 `t` 预测未来 `H` 时间后的血糖，那么：

- 输入：截至 `t` 的历史 CGM 序列
- 预测目标：`t + H` 时刻的 CGM 目标值
- 预测时距：`H`

实际研究还需说明窗口长度、采样间隔、预测步数和标签构造方法。

## 7. CGM 研究中的数据泄漏风险

时间序列数据常通过滑动窗口构造训练样本。相邻窗口可能共享大量观测值。如果先构造窗口，再随机拆分训练集和测试集，可能导致高度相似甚至重叠的片段进入不同数据集，使测试结果过于乐观。

研究开始前应先明确评估目标，并据此设计拆分方式：

- 如果目标是预测已见过的个体未来数据，应按时间顺序拆分，并确保测试时间段晚于训练时间段。
- 如果目标是评估对新个体的泛化，应确保测试集受试者与训练集受试者分离。
- 预处理参数、归一化统计量和特征选择结果应仅由训练数据估计，再应用到验证集和测试集。

数据拆分方式应与论文声称的应用场景一致，并在实验记录中说明。

## 8. 评价 CGM 或预测模型时应注意什么？

CGM 设备性能评估与预测模型性能评估不是同一问题：

- **设备评估：** 关注传感器估计值与参考测量之间的一致性、误差及数据可用性。
- **预测模型评估：** 关注模型对未来目标值或风险类别的预测表现。
- **闭环系统评估：** 关注使用这些信息后，完整控制系统的表现。

如果报告 MARD（mean absolute relative difference，平均绝对相对差），应说明参考测量、数据配对方式和分析样本。MARD 是常见的汇总指标，但不宜脱离研究条件单独用来比较设备或模型。

预测研究还应报告与任务相匹配的误差指标、预测时距和数据划分方式。总体平均误差不能替代对个体差异、低值区间或数据缺失的分析。

## 9. 阅读 CGM 论文时的检查清单

- [ ] 研究使用的 CGM 设备或数据来源是什么？
- [ ] 数据采样间隔和时间戳如何定义？
- [ ] CGM 读数与参考测量是否区分清楚？
- [ ] 单位是否统一？
- [ ] 缺失值、异常值和不规则采样如何处理？
- [ ] 预测目标、历史窗口和预测时距是否明确？
- [ ] 训练集、验证集和测试集如何划分？
- [ ] 相邻滑动窗口是否可能造成数据泄漏？
- [ ] 结果是否按个体、时间段或目标区间进一步分析？
- [ ] 研究结论是否超出了数据与验证设计能够支持的范围？

## 10. 本仓库的数据规范

- 不上传未获准公开的患者数据、身份信息、访问凭据或受限数据集。
- 对数据集只记录公开来源、申请方式、使用许可、字段说明和引用要求。
- 保留数据来源、版本、获取日期和预处理步骤。
- 明确区分原始数据、处理后数据、模型输入和预测标签。
- 仅在许可允许的情况下分享数据或衍生文件。
