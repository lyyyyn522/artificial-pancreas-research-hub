# Artificial Pancreas Research Hub

Knowledge, reproducible experiments, and writing workflows for artificial pancreas and glucose prediction research.

## 研究目标

1. 整理人工胰腺、连续血糖监测与血糖预测的基础知识和文献。
2. 逐步建立可复现的血糖预测模型与评估实验。
3. 分别探索 LLM 辅助文献研究、血糖预测及尚待验证的研究设想。
4. 沉淀论文写作、引文核对和科研图表制作流程。

## 仓库结构

仓库正在建设中，计划包含：

- `knowledge/`：核心概念与研究笔记
- `literature/`：论文阅读卡与参考文献
- `datasets/`：数据集来源、获取条件与字段说明
- `models/`：预测模型与基线
- `paper/`：论文写作、图表和排版流程

## 使用边界

本仓库仅供科研与学习，不提供个人医疗建议或自动给药决策。
不上传未获准公开的患者数据、访问凭据或受限数据集。
研究设想与经过复现的结果会明确区分。
