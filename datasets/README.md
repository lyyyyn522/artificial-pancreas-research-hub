# 数据集目录

本目录用于登记与人工胰腺、连续血糖监测（CGM）和血糖预测研究相关的数据集及其使用条件。

## 计划记录的信息

- 数据集名称、来源和官方链接
- 研究对象与数据规模
- 包含的变量与采样频率
- 数据获取方式及申请要求
- 使用许可、隐私限制和引用要求
- 适用的研究任务与已知局限

## 计划内容

- `dataset-catalog.md`：数据集目录与对照表
- `data-dictionary/`：字段与变量说明
- `protocols/`：数据清理、划分和预处理规范

## 数据安全

- 不在本仓库上传未获准公开的患者数据、可识别信息或受限原始数据。
- 仅记录公开的数据集链接、申请流程和使用条件。
- 使用数据前，先核对数据提供方的许可、伦理和引用要求。
