# 文献库

本目录用于系统整理人工胰腺、连续血糖监测、血糖预测及相关 AI 方法的研究文献。

## 计划内容

- `reading-notes/`：单篇论文阅读卡
- `reviews/`：综述与专题文献梳理
- `references.bib`：核对过的 BibTeX 文献记录

## 文献阅读卡建议记录

论文题目、作者、年份、期刊或会议、DOI/原文链接、研究问题、数据集、方法、预测时距、数据划分、评价指标、主要结果、局限性，以及本仓库如何使用这篇文献。

## 规范

- 尽量链接论文原文或 DOI，不只记录搜索结果摘要。
- 区分已正式发表论文、预印本和待验证观点。
- 不把 AI 生成的摘要直接当作论文结论；关键结论应回到原文核对。
