# 模型目录

本目录用于整理和实现人工胰腺研究中的血糖预测模型及相关控制方法。

## 研究范围

- **血糖预测**：预测未来血糖值或低血糖等风险事件。
- **控制与决策**：研究如何利用预测结果进行胰岛素输注等控制。
- 两类任务分别记录、评估；预测性能不能单独证明控制策略安全有效。

## 计划内容

- `baselines/`：简单基线模型
- `forecasting/`：传统机器学习与深度学习预测模型
- `control/`：仿真环境中的控制方法
- `model-cards/`：模型用途、数据、评估结果、限制和风险说明

## 模型记录规范

每个模型尽量说明：研究任务、输入与输出、预测时距、数据集、数据划分、评价指标、训练配置、复现步骤、结果及已知局限。

## 安全边界

本目录中的模型仅用于科研与教学，不用于个人诊断、治疗建议或真实设备的自动给药。
